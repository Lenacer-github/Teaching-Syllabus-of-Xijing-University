# 数据目录

## 全院课程总表

请将全院统一课程总表放在：

```text
data/course_codes.xlsx
```

程序也兼容：

```text
data/course_code.xlsx
```

推荐使用 `course_codes.xlsx`，保持和系统文档一致。

课程总表第一行为表头，从第二行开始每行一门课。建议表头如下：

- 课程代码
- 课程名称（中文）
- 课程名称（英文）
- 课程类别
- 课程性质
- 学分
- 总学时
- 理论学时
- 实践学时
- 开课学期
- 考核方式（考试考查）

课程类别填写范围：通识教育课程、公共基础课程、专业教育课程、个性化课程、实践教育课程。

课程性质填写范围：必修、选修。

考核方式填写范围：考试、考查。

## 人才培养方案

每个专业的人才培养方案 PDF 放在对应专业目录：

```text
data/programs/<专业代码>/training_plan.pdf
```

例如：

```text
data/programs/guomao/training_plan.pdf
```

程序会从人才培养方案中尽量提取：

- 课程开课学期
- 课程对毕业要求的 H/M/L 支撑关系
- 毕业要求和指标点的完整文本

如果 PDF 表格复杂，建议使用 LlamaParse API。没有配置 API Key 时，系统会退回到本地基础 PDF 文本提取，但表格识别准确率会明显下降。
