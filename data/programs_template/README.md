复制本目录作为新专业目录，并放入以下文件：

- `program.yaml`：专业名称、代码、实践学时比例等配置
- `training_plan.pdf`：专业人才培养方案

`training_plan.pdf` 文件名必须保持一致。系统会用它核对课程开课学期、毕业要求支撑矩阵和毕业要求指标点内容。

课程编码表不再放入单个专业目录。请将全院课程总表统一放在：

```text
data/course_codes.xlsx
```

课程总表建议包含以下列：

- 课程代码
- 课程名称（中文）
- 课程名称（英文）
- 课程类别
- 课程性质
- 学分
- 总学时
- 理论学时
- 实践学时
- 开课学期
- 考核方式（考试考查）
